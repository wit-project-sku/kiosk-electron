# Customer-display videos (2nd monitor)

Drop `.mp4` (or `.webm`) files here. They play full-screen on the 2nd monitor by
default and loop in filename order. When a visitor starts the AI 한복 photo flow,
the 2nd monitor automatically switches to the live camera → countdown → AI
result, then returns to these videos.

If this folder is empty, the 2nd monitor shows a simple attract title instead.
